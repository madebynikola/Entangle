## Model-Driven AUTOSAR SWC Configuration Generation from System Extract via DaVinci API

**Company:** DriveLogic Vojvodina d.o.o. works in automotive and mobility software. [C018] Challenge C018-CH1.  
**Researcher:** Milana Bošković is an Assistant Professor in the Department of Computing and Control Engineering, Faculty of Technical Sciences. [R0341]  
**Format:** joint project, one page.

### The problem
DriveLogic manually generates 3,200 AUTOSAR SWC configuration files per project, a task that takes two senior engineers three weeks of repetitive mapping work. [C018-CH1, C018] A competitor reportedly completed the same task in four days using automation, making the manual process a competitive liability. [C018-CH1] The company targets a reviewable first-draft configuration set produced in under one working day from a System Extract input. [C018-CH1]

### Research questions
1. Can a DSL-driven model-to-model transformation, fed a System Extract, generate a complete first-draft ARXML configuration set via the DaVinci API that passes the company's internal review checklist without manual rework on the mapping rules — measured against reviewer acceptance rate on 10 real project System Extracts?
2. Does the generated configuration set meet the one-working-day target end-to-end (parse, transform, write) — measured as wall-clock time from System Extract input to a DaVinci-importable ARXML set on the three largest active project extracts?

### Approach
- Define a lightweight domain-specific language (DSL) that captures the mapping rules between System Extract fields and AUTOSAR SWC configuration parameters, encoding customer naming conventions and coding rules as first-class constraints — following the architectural-model-to-configuration approach in Bošković's work on API gateway configuration generation.
- Build model-to-model transformations (using ATL or a comparable rule engine) that read the DSL mapping rules and drive generation of ARXML fragments via the DaVinci API — applying the mismatched-interface adapter generation method from Bošković's prior work.
- Seed the DSL with the company's existing Excel-based templates so the tool's initial mapping rules reproduce known-good outputs; validate each generated file by re-importing it into DaVinci Configurator and running the company's review checklist.
- Measure end-to-end generation time and reviewer acceptance rate on real project System Extracts to answer both research questions and confirm the one-working-day target is met before handover.

### Plan

Wall-clock generation time and reviewer acceptance rate are measured against both research questions. ### First six months
- Month 1: The company provides three real System Extract files and the DaVinci API documentation to the research group under a data-use agreement. The master's student sets up a version-controlled repository; the company engineer holds two onboarding sessions on the manual configuration workflow.
- Month 2: The student documents the System Extract schema and maps every field type to its target AUTOSAR SWC configuration parameter; the company engineer reviews and approves the mapping table.
- Month 3: Bošković and the student draft the DSL grammar; the company engineer encodes the existing Excel-template rules into the DSL and validates that the DSL can represent all mapping cases from the three extracts.
- Months 4–6: The student implements and iterates the ATL transformation engine; generated ARXML files are imported into DaVinci Configurator by the company engineer and checked against the review checklist each sprint.

### Why this pair
The company has a well-scoped bottleneck — mechanical mapping from a structured input to a structured output format — and real data ready to test on. Bošković brings the two methods the problem needs: DSL-driven configuration generation and ATL model-to-model transformation. Neither side could do it alone: the company has the domain knowledge, the DaVinci API access, and the real project data that ground the tool in practice; the research group brings the transformation engineering methods and a master's student to build and validate them.
